Short release summaries for GitHub discovery. The official source of truth is the [MCPlato changelog](https://mcplato.com/en/changelog/).

## v2.1 — AI Partner

MCPlato v2.1 marks a positioning upgrade from an AI workspace into an **AI Partner**. The desktop experience and runtime engine have been rebuilt around partner-style workspaces, multi-window collaboration, and faster parallel AI work.

### Highlights

- **Every workspace is a teammate** — each partner has its own name, avatar, memory, and area of expertise.
- **A home for your whole team** — a persistent home window shows partner status, unread messages, and update progress.
- **Multi-window mode** — each partner can have its own window across multiple screens.
- **Detachable tabs** — drag a tab out to create a new canvas, then drag it back to merge automatically.
- **Faster local inference engine** — startup, first token, and tool calls are noticeably quicker for new sessions.
- **True parallel work across partners** — long-running tasks no longer block other partners or conversations.
- **Long tasks continue more reliably** — memory is reorganized as the context limit approaches so key information is preserved.
- **Smarter permission auto-allow** — permission handling is centrally managed and dangerous operations remain blocked automatically.
